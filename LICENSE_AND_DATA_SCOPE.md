## Data acquisition and reconstruction

Raw task snapshots are not distributed in this release. Users retrieve them from official sources, verify the recorded upstream SHA-256 values and versions, and run deterministic preparation and split-reconstruction code. The project supplies upstream provenance, stable task identifiers, checksums, processed/split manifests and reconstruction scripts. Access and use remain subject to upstream terms.
