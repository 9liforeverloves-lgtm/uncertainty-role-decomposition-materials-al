# Evidence class definitions

- **V5-RC1**: immutable prior confirmatory evidence; seeds 5000–5039; never pooled with V6.
- **V6-MECH**: calibration/acquisition decoupling, beta matching, ranking and path mechanisms.
- **V6-EXT**: non-tree model, non-UCB acquisition and genuinely external dataset.
- **V6-SENS**: stronger OOD, campaign geometry and Historical-CS ablations.
- **V6-REP**: raw prediction vectors, NLL diagnostics and reproducibility validation.

Development, confirmation, exploratory and descriptive labels remain distinct within each class.
