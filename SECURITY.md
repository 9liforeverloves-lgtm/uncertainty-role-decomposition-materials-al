# Security policy

Never place API keys, archive tokens, private keys or credentials in issues,
commits, workflow files or release archives. GitHub/Zenodo credentials must be
stored only in the hosting platform's encrypted secret store after author
approval.

Report a suspected vulnerability privately through the security-advisory
feature of the future public repository. Until a public repository exists,
contact the author through an independently verified institutional channel.
Do not include live credentials in a report.
